# Artfolio frontend

Одностраничный адаптивный frontend портфолио на React, TypeScript, Vite и Material UI.

## Запуск

Требуется Node.js 22.

```bash
npm ci
npm run dev
```

Проверки:

```bash
npm run lint
npm run build
```

## Источники данных

Публичный сайт и административная панель работают с REST API `/api/v1`. Клиентские запросы находятся в `src/services`, транспортные типы — в `src/types`.

Изображения работ загружаются через административную панель и отображаются по URL, возвращённым backend. Если опубликованных работ нет, интерфейс показывает состояние пустой галереи и нейтральный placeholder первого экрана.

Палитра, шрифты и основные параметры интерфейса находятся в `src/theme`.

При локальном запуске настройте proxy для `/api` и `/media` на backend. В production эти маршруты обслуживает Caddy.
